\begin{abstract}
This project predicts daily bike rental demand for the 20 most used Capital Bikeshare start stations. The problem is formulated as supervised regression with \code{total\_rentals} as target. The main contribution is not only the final model score, but the structured path from raw data to a reproducible modelling pipeline: raw trip, station, and weather data are aggregated to station-day level; leakage-prone count decompositions are removed; redundant weather predictors are reduced using correlation analysis; station identity is represented with one-hot encoding; and exact station-specific lag features are added. All models are evaluated with the same chronological train-validation-test split and the same metrics. The final best model is Gradient Boosting with lag features, reaching a test RMSE of 22.78, MAE of 16.92, and $R^2$ of 0.663. The clearest result is that temporal representation matters most: adding lag features improves test RMSE for every evaluated model.
\end{abstract}
