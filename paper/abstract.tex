\begin{abstract}
This project predicts daily bike rental demand for the 20 most used Capital Bikeshare start stations. We formulate the task as supervised regression with \code{total\_rentals} as target and build a reproducible pipeline from raw trip, station, and weather data to final evaluation. Key preprocessing steps include leakage removal, correlation-based feature reduction, one-hot encoding of station IDs, and station-specific lag features. Using a chronological train-validation-test split, the best model is Gradient Boosting with lag features, reaching a test RMSE of 22.78, MAE of 16.92, and $R^2$ of 0.663. The main finding is that temporal representation matters most: lag features improved every evaluated model.
\end{abstract}
