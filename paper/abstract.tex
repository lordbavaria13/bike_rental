\begin{abstract}
Accurately forecasting bike rental demand is essential for optimizing modern bike-sharing operations. This report presents a comprehensive machine learning workflow to predict daily rentals using Capital Bikeshare usage statistics and historical meteorological metrics. We formulate the forecasting task as a regression problem and establish a structured data processing pipeline focused on high-traffic stations to ensure reliable signal extraction. To simulate real-world forecasting conditions, we evaluate eight different regression models—ranging from linear baselines to advanced ensemble techniques—under a strict chronological train-validation-test split. A detailed performance comparison using multiple error metrics, including RMSE, MAE, and $R^2$, reveals that tree-based ensemble methods significantly outperform linear models. Gradient Boosting proved most effective during validation, while Random Forest achieved the best generalization on the held-out test set. Finally, we critically reflect on these results, concluding that while weather and calendar features provide strong predictive power, future iterations must address uncaptured temporal dependencies to further enhance operational forecasting.
\end{abstract}
