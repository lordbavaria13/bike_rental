\begin{abstract}
This project predicts daily bike rentals for the 20 most used Capital Bikeshare start stations as a supervised regression task. We build a reproducible pipeline from trip, station, and weather data, including leakage removal, feature reduction, one-hot station encoding, and station-specific lag features. The best model is Gradient Boosting with lag features. The main result is that temporal representation matters most: lag features improved every evaluated model.
\end{abstract}
