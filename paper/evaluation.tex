\section{Evaluation Strategy}
\label{sec:evaluation}

The main ranking metric is RMSE because large demand errors are more 
problematic in practice than small ones. However, one metric alone is 
not enough to fully understand model behaviour. The final comparison 
therefore reports six metrics plus runtime information.

\subsection{Hyperparameter Tuning}

Hyperparameters were tuned using the validation set only. The test set 
was not used until the final evaluation. This separation is important 
because choosing parameters based on test performance would make the 
final score too optimistic -- the test set would effectively become 
a second development set. The best parameter combination for each 
model was selected by the lowest validation RMSE.

\subsection{Overfitting Diagnosis}

Overfitting is detected by comparing train, validation, and test RMSE 
for each model. A large gap between training and test performance 
indicates that the model has memorized the training data instead of 
learning general patterns. KNN and single decision trees are the most 
likely candidates because they can fit very locally to the training 
data. Regularized linear models are more stable but may underfit 
nonlinear demand patterns. Ensemble methods like Random Forest and 
Gradient Boosting are expected to generalize better, but Gradient 
Boosting still requires careful tuning because deep or numerous trees 
can also overfit.
