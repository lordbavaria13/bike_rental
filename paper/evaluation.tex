\section{Evaluation Strategy}
\label{sec:evaluation}

The main ranking metric is RMSE because large demand errors are more 
problematic in practice than small ones. Since one metric alone cannot 
describe model behaviour completely, we also report MAE, Median AE, 
MAPE, $R^2$, and explained variance.

\subsection{Hyperparameter Tuning}

Hyperparameter tuning was performed in two stages. First, all models 
were tuned once using validation RMSE. This made the comparison fair 
because each model family received a suitable basic configuration 
instead of relying only on default settings.

Second, the strongest candidates from the first comparison were tuned 
again more carefully. This focused on parameters controlling model 
complexity and generalization, such as the learning rate and number of 
estimators for Gradient Boosting or regularization strength for Lasso 
and the Neural Network. In both stages, the test set was not used for 
parameter selection. It was used only once for the final evaluation.

\subsection{Overfitting Diagnosis}

Overfitting is diagnosed by comparing train, validation, and test RMSE. 
If the training error is much lower than the validation and test error, 
the model has learned patterns that do not generalize to future data. 
This is most visible for KNN and the single Decision Tree, which fit 
local training structures too closely.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=\columnwidth]{rmse_comparison.png}
    \caption{Train, validation, and test RMSE across models. Large gaps 
    between training and test RMSE indicate overfitting. KNN and the 
    single Decision Tree show the clearest pattern, while ensemble 
    methods generalize more reliably.}
    \label{fig:rmse_overfitting}
\end{figure}

Regularized linear models are stable but may underfit nonlinear demand 
patterns. Ensemble methods reduce this problem: Random Forest lowers 
variance by averaging many trees, while Gradient Boosting sequentially 
corrects remaining errors. Fig.~\ref{fig:rmse_overfitting} supports the 
final model choice because Gradient Boosting offers a strong balance 
between flexibility and generalization, while still requiring careful 
tuning to avoid overfitting.
