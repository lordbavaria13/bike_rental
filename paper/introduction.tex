\section{Introduction}

Accurately predicting bike rental demand is a crucial operational challenge for bike-sharing systems. The goal of this project is to forecast this demand using machine learning in a way that is technically sound, reproducible, and easy to justify. 

To achieve this, we frame the task as a regression problem, utilizing daily data from the Capital Bikeshare system combined with historical weather metrics. This report combines two core phases of the project into one coherent document:

First, it outlines the complete data preparation and feature engineering process. Explaining the final reduced dataset is essential, because the modelling results only make sense if the underlying data representation is clear and robust.

Second, it presents the modelling pipeline and the final evaluation. We train and compare eight different regression models under a strict chronological train-validation-test split. The report provides a detailed performance analysis using error metrics such as RMSE, MAE, and $R^2$. By summarizing these results in comparative tables and visual diagnostics, we evaluate which models perform best, interpret their behavior, and critically discuss the current limitations of our forecasting system.
