\section{Introduction}
Bike-sharing systems depend on local and time-dependent demand. If too few bikes are available, users cannot start trips; if too many bikes accumulate at one station, docks and redistribution capacity are wasted. We therefore study the following machine learning question: given station, calendar, weather, and recent demand information, how accurately can daily bike rentals be predicted for a station?

The task is a supervised regression problem because the output is a numeric rental count. The final target is \code{total\_rentals}. The main input groups are station identity, weather, calendar variables, chronological order, and lagged demand. The project deliberately focuses on a transparent pipeline rather than a single black-box result. Each data transformation is justified because the final model quality depends strongly on representation choices.
