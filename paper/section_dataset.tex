\section{Dataset Construction and Used Features}
The raw project data contains trip usage information, station metadata, and weather data. The final learning table is not the raw trip table. It is a reduced and reproducible station-day dataset: one row means one start station on one calendar day, and the target is the total number of rentals started at that station on that day. This reduction is necessary because it aligns trip counts with daily weather information, gives a clear target variable, and avoids mixing row granularities.

\subsection{Target Variable and Distribution}
The target was simplified to one output, \code{total\_rentals}. Intermediate count columns for member/casual users or bike types were removed from the predictor set because they are components of the same total. Keeping them would create a leakage-like shortcut: the model could reconstruct demand instead of forecasting it.

\subsection{Why the Top 20 Stations Were Used}
The top-20 filter is a methodological reduction. Rare stations contain fewer repeated observations, which makes station-specific patterns unstable and weakens evaluation. Highly used stations provide enough examples for model comparison and reduce random noise. The limitation is explicit: the final model represents busy stations, not the complete bikeshare system.
